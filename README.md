# My Calculator Project

Αυτό είναι ένα απλό project υπολογιστή (calculator) που δημιουργήθηκε για εκπαιδευτικούς σκοπούς. Παρέχει βασικές αριθμητικές λειτουργίες όπως πρόσθεση, αφαίρεση, πολλαπλασιασμός και διαίρεση.

## Λειτουργίες

- Βασικές αριθμητικές λειτουργίες: πρόσθεση, αφαίρεση, πολλαπλασιασμός, διαίρεση
- Διαισθητική διεπαφή χρήστη (CLI ή GUI)
- Εύκολο στην επέκταση για προσθήκη νέων λειτουργιών (π.χ. επιστημονικές συναρτήσεις)

## Τεχνολογίες

| Τμήμα          | Τεχνολογία                             |
|----------------|-----------------------------------     |
| **Backend**    | Java                                   |
| **Frontend**   | CLI (Διασύνδεση Γραμμής Εντολών) ή GUI |
| **Build Tool** | Maven ή Gradle                         |
| **IDE**        | IntelliJ IDEA, Eclipse, VS Code        |

## Εκκίνηση
